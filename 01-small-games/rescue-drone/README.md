# Rescue Drone

Rescue Drone is a beginner Python terminal game I built to practice core programming concepts.

The player controls a rescue drone that travels between locations, manages battery, rescues survivors, and returns them safely to Base.

## Features

- multiple locations with different risk levels
- battery-based travel
- random rescue success
- survivors remaining, onboard, and saved
- increasing rescue cost
- return-to-base safety checks
- upgrade rolls
- multi-roll rescue system
- game-over conditions

## Python Concepts Practiced

- variables
- functions
- lists
- dictionaries
- `if` / `elif` / `else`
- `for` and `while` loops
- `break` and `continue`
- Boolean values
- `random.randint()`
- input validation
- managing changing program state

## What I Learned

This project helped me move from small Python exercises to a larger program where many variables, functions, loops, and conditions work together.

It also taught me a lot about debugging control flow and keeping game state consistent.

## Running
